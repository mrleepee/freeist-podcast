We have been building sovereign AI agent stacks in this series. We covered the v zero point fourteen Foundation Release and ten Hermes Agent features you probably aren't using yet. Now we go one step further into the exact mechanics of version zero point seventeen point zero. They call it the Reach Release. It landed on June nineteenth, twenty twenty-six. If you want to understand how much an open-source project can mature in a single month, look at the raw numbers. Between version zero point sixteen point zero and this build, the community merged roughly eight hundred pull requests from two hundred forty-five contributors. They closed over three hundred issues across approximately one thousand four hundred seventy-five commits. That is not a minor patch. It is a structural expansion of where and how your agent operates.

The first major feature is iMessage integration via Photon Spectrum. You run a single login command, authenticate with a device code, and Hermes can send and receive messages natively. No Mac sitting in a closet acting as a relay. No BlueBubbles bridge for you to babysit. In a recent video walkthrough, Alex Finn demonstrated this by asking the agent from his phone to check a stock price and explain why it moved. The reply came back directly in the native message thread with full rich formatting. That demonstration lines up with the changelog, though it is just a proof of concept, not a separate feature. The second feature connects Hermes to the Raft agent network as a gateway channel. The privacy design here is explicit. Wake payloads carry only metadata, things like event identifiers and timestamps. Message bodies are never exposed or transmitted in the wake cycle.

The third feature deepens the native desktop application that shipped in version zero point sixteen. The changelog adds rebindable keyboard shortcuts, native operating system notifications, and live subagent watch-windows that stream a delegated agent's activity into its own pane. You also get a composer model selector, automatic right-to-left text direction, and the ability to install any Visual Studio Code Marketplace theme directly into the app. The fourth feature introduces non-blocking background subagents. You set the delegation task parameter to background equals true, and Hermes dispatches a subagent that runs silently and returns a handle immediately. You and the primary model keep working. The full result re-enters the conversation as a new turn the moment the background task finishes.

The fifth feature brings image-to-image editing directly into the standard image generation tool. You pass an existing image and a prompt, and it routes to the backend's edit endpoint across every supported provider. The sixth feature replaces tedious cron scheduling with Automation Blueprints. You pick an automation by name, and Hermes asks you what it needs through a question-driven form. One blueprint definition renders natively as a dashboard form, a slash command, or a conversational prompt. The seventh addition is the Cursor Composer fast coding model, available through your existing xAI Grok OAuth subscription with a full two hundred thousand token context window. The eighth feature targets silent token drains. The Curator now prunes stale skills by default, but it no longer runs its large language model-powered consolidation pass unless you explicitly opt in via a config file flag. Routine background curation now costs you zero tokens.

Apply the logic behind that Curator optimization to your own harnesses immediately. Autonomous agents that silently trigger auxiliary model calls for routine housekeeping will bleed your budget dry. That is why making token-spending consolidation an explicit opt-in flag is a necessary architectural pattern. You must separate deterministic, free operations from expensive, opinionated model inference.

This release is about extending operational reach without surrendering control or capital. Version zero point seventeen gives you deeper desktop integration and asynchronous delegation while closing the loop on background token expenditure. The infrastructure expanded. The silent costs got neutralized.
