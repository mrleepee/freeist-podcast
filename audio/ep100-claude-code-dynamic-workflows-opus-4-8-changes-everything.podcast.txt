Anthropic just changed what a coding assistant even means. Opus four point eight dropped with a feature that moves Claude Code from something that answers your questions to something that runs entire operations without you watching. Dynamic workflows landed this week, and they represent a fundamental shift in how you coordinate A I assistance at scale.

Let me explain what this actually is. A dynamic workflow is a JavaScript script that the Claude Code runtime executes in the background while your session stays responsive. You describe what you want to accomplish, Claude writes the orchestration script, and the runtime runs it. The script coordinates the agents. Your conversation only holds the final answer. That separation between what you want and how it gets done is the key insight here.

Now, you might be thinking this sounds like subagents or skills, and you would not be wrong to draw that comparison. With subagents and skills, Claude is the orchestrator. It decides turn-by-turn what to spawn next, and every result lands in Claude's context window. A workflow moves the plan into code. The script holds the loop, the branching logic, and the intermediate results in variables. Claude's context only ever sees the final answer. That is a fundamentally different architecture.

The scale is where things get interesting. You can run up to sixteen concurrent agents and up to one thousand total per run. One thousand. That is not a handful of helpers on a task. That is a department. A codebase-wide audit, a five-hundred-file migration, multi-source research with cross-checking — tasks that previously required careful turn-by-turn management can now be codified, rerun, and shared as commands. The script is readable, auditable, and repeatable. You are trusting a plan you can inspect before it runs, not Claude's in-the-moment judgment.

Here is where it gets clever. Because the plan is code, you can apply repeatable quality checks. Independent agents can adversarially review each other's findings before they are reported. You can draft a plan from several angles and weigh them against each other. The result is more trustworthy than a single pass. That is something you cannot do with a conversational assistant.

Triggering a workflow is straightforward. Two ways. First, include the word "workflow" anywhere in your prompt and Claude writes a workflow script instead of working turn-by-turn. Second, set a directive called "effort ultracode" and Claude automatically plans a workflow for every substantive task in the session. Ultracode combines high reasoning effort with automatic workflow orchestration. The deep research feature, which is the first bundled workflow, fans out web searches across several angles, fetches and cross-checks sources, votes on each claim, and returns a cited report with claims that did not survive cross-checking filtered out. That is a research assistant that cannot fudge the sources.

When a workflow does exactly what you want, you press the save key in the workflows view and it saves as a command. Saved workflows appear in the autocomplete alongside the bundled ones. You can save to a dot-claude slash workflows folder in your project for team sharing, or to a workflows folder in your home directory for personal use. And if you stop a run midway through, you can resume it within the same session. Agents that already completed return their cached results. The rest run live.

There are limitations worth knowing. You cannot provide input mid-run — only agent permission prompts can pause execution. The script itself has no direct filesystem or shell access. Agents do the reading, writing, and command execution. Runs count toward your plan's usage and can use significantly more tokens. And resume only works within the same Claude Code session — exit and the next session starts fresh.

But here is the implication. This moves Claude Code from a conversational assistant to a batch orchestration engine. Anthropic is betting that the next leap in developer productivity is not a smarter single model but better coordination of many agents. Dynamic workflows are the orchestration layer. Combined with ultracode mode, Claude Code is moving toward autonomous operation where you describe the outcome and the system figures out the plan, writes the script, and executes it. That is not a feature update. That is a different product category.
