En este episodio vas a aprender tres cosas: primero, qué son los nuevos créditos para uso automático de Claude. Segundo, cuánto dinero recibes con cada plan. Tercero, cómo este cambio afecta a los usuarios que usan Claude en segundo plano.

Si usas Claude para trabajo automático, esto te interesa mucho. A partir del 15 de junio, todo cambia para los usuarios de los planes de pago de Claude.

Anthropic, la empresa que crea Claude, announce un nuevo sistema de créditos. Cada mes, los usuarios con planes de pago reciben créditos especiales para usar Claude de forma automática. Un plan Pro recibe 20 dólares. El plan Max 5 recibe 100 dólares. El plan Max 20 recibe 200 dólares. Estos créditos son solo para trabajo automático. No son los mismos créditos que ya conoces para conversaciones normales.

Pero ¿qué significa trabajo automático? Es cuando Claude trabaja solo, sin que una persona esté ahí. Por ejemplo, cuando usas Claude Agent SDK para correr Claude en tus proyectos. También cuando usas Claude Code en tu computadora. O cuando Claude hace trabajo en GitHub Actions automáticamente. Todo esto ahora necesita créditos especiales.

Antes, podías usar tus créditos normales para todo. Podías hablar con Claude y también podías usarlo de forma automática. Era un solo presupuesto. Ahora es diferente. Los créditos para conversaciones se quedan igual. Pero los créditos para uso automático son separados y más pequeños.

Esto es muy importante. Para algunos usuarios, el cambio es enorme. Imagina que antes podías usar hasta 5.000 dólares en uso automático con el plan Max 20. Ahora solo tienes 200 dólares para eso. Es una reducción muy grande. La compañía está diciendo claramente: preferimos que uses Claude hablando con una persona, no trabajando solo.

Algunos usuarios ya están diciendo que van a usar otras opciones. Por ejemplo, hay personas que planean mover su trabajo automático a Codex, que es de OpenAI. Piensan que там получаешь más valor por tu dinero. Pero van a seguir usando Claude Code para trabajo normal, cuando una persona está ahí guiando todo.

El mensaje final es simple. Anthropic está priorizando el uso donde hay una persona interactuando con Claude. Si tu trabajo depende mucho de automatización, necesitas pensar en tus opciones. Puedes aceptar los nuevos límites o buscar alternativas.

Hoy aprendimos que Claude ahora tiene créditos separados para uso automático. Los planes de pago ofrecen entre 20 y 200 dólares mensuales para este tipo de trabajo. La compañía quiere que los humanos estén más involucrados en las conversaciones con Claude, no menos.
