Codex version 0.129.0 has just landed, bringing five shiny new features that are bound to make your workflow feel a bit slicker. If you’ve been keeping an eye on the changelog you’ll have noticed that Felipe Coury, the resident mastermind behind many of the cheeky crab‑themed Easter eggs that pop up in the interface, has been busy squashing bugs and adding a handful of nifty tools. Today we’re going to walk through the standout additions so you can jump in and start using them straight away.

First on the list is the brand‑new keymap debug tool. Imagine you’re remapping keys in your favourite editor and suddenly you’re not sure whether the terminal is receiving the right input. The new `/keymap` or `/keymap debug` command drops you straight into a diagnostic view that translates every keypress on the fly. It shows you exactly which keys are being captured and how they’re being interpreted, which is an absolute godsend for anyone who loves to tweak their shortcuts. No more scratching your head over a stubborn binding—just fire up the debug view, watch the key traffic roll by, and you’ll have the answer in seconds.

Next up, the status line has received a couple of thoughtful enhancements that will save you a few clicks each day. The updated bar now proudly displays the pull‑request number you’re currently working on, as well as the branch changes you’ve made. And here’s the clever bit: both of these items are clickable, but only when you hold down the Command key on a Mac (or the equivalent modifier on your OS). Clicking them opens the corresponding PR or branch in your browser, which is a brilliant shortcut for those of us who constantly jump between the terminal and GitHub. It’s the kind of small, tactile improvement that makes the whole experience feel a lot more fluid.

If you’ve ever longed for the power of Vim without having to leave Codex, you’ll be delighted to hear that the third feature is a built‑in Vim emulation layer. It’s not a full‑blown Vim install, but a carefully crafted set of modal keybindings that let you navigate, edit and manipulate code using familiar Vim commands. You can toggle it on and off with a simple `/vim` command, and the mode indicator appears right in the status bar so you always know where you stand. Whether you’re a die‑hard Vim user or just curious, it’s a fantastic way to bring the efficiency of modal editing into Codex without missing a beat.

The fourth addition is a fun one, and it comes courtesy of Felipe’s love for all things crab‑themed. The development team has tucked a delightful Easter egg into the UI: a subtle crab icon that appears in the corner of the debug view whenever you activate the keymap tool. It’s a tiny touch, but it’s already become a talking point in the community and a nice morale boost during long debugging sessions. Keep an eye out for it—the crab pops up only for a moment, so you’ll need to be quick!

Rounding out the release is an upgraded snippet manager that makes inserting reusable blocks of code a breeze. The new `/snippet` palette lets you browse, search and insert snippets on the fly, and you can even create your own personal library with a simple `/snippet add` command. The palette respects your current file type, so it will only show relevant snippets, and you can preview each one before inserting it. It’s a small quality‑of‑life improvement that can shave minutes off your daily routine, especially when you’re working with repetitive patterns across a large codebase.

All in all, version 0.129.0 delivers a nicely balanced mix of productivity boosters and little surprises that keep the Codex experience fresh and enjoyable. Be sure to update your installation, give the keymap debug a spin, try out the new Vim mode, and see if you can spot the crab. And if you create any handy snippets, share them with the community—after all, the best tools are the ones we build together. Happy coding, and I’ll catch you on the next episode.
