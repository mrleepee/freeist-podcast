In this episode you'll learn two things: how to build a completely local, AI-powered knowledge base that never loses your data, and how to automate the tedious work of organising notes so you can focus on asking questions and exploring ideas.

The frustration of modern note-taking is familiar to most of us. You save tweets, bookmark articles, dump thoughts into Notion, and end up with hundreds of isolated notes that never connect to each other. Every time you ask an AI a question, it starts from scratch with no accumulated memory, burning through tokens on context it shouldn't need to rebuild. And perhaps worst of all, your notes live on someone else's servers, which means if a service shuts down or changes its terms, your knowledge disappears overnight.

This system tackles all of those problems by combining three tools into one seamless workflow. The core idea is simple: import any document, let the AI organise it automatically, generate a persistent wiki with bidirectional links, and then query your knowledge base whenever you need answers. No manual tagging, no clicking through folders, no starting from zero each time.

Obsidian serves as the presentation layer. It's a free, local note-taking application that creates what are called bidirectional links. When you type double brackets around a term like [[project-management]], Obsidian automatically turns it into a clickable link. If that note already exists, clicking takes you there. If it doesn't, clicking creates it on the spot. The Graph View feature lets you visualise your entire knowledge network as a diagram, showing which topics are well-connected hubs and which remain isolated. Crucially, everything stays on your own machine. Nothing uploads anywhere.

Hermes Agent, developed by Nous Research, acts as the automated execution engine. It has a built-in learning loop that actually improves how it handles tasks over time. When you ask it to write something into the knowledge base, it doesn't just save the file. It extracts key entities like people, tools, and projects, identifies core concepts and methodologies, creates properly structured markdown files, adds bidirectional links connecting related ideas, and updates the master index. The important rule is that Hermes only touches your knowledge base when you explicitly tell it to. Daily conversations stay separate, which keeps your knowledge base clean and relevant.

LLM Wiki isn't a separate application but rather a file structure specification. It defines where things go: a raw sources folder for original documents, an entities folder for people and tools, a concepts folder for principles and methodologies, plus index and changelog files. When you import a new document, the system genuinely understands the content rather than simply indexing it. It extracts relationships, creates or updates wiki pages, and cites sources so you always know where conclusions came from.

The workflow is beautifully straightforward. You open Hermes, say write this article into the knowledge base, and it handles everything automatically. Then you open the knowledge base folder in Obsidian and browse your curated network with navigable links and a visual graph showing how topics connect. Each new import enriches existing pages and creates fresh connections. Over time your knowledge base becomes increasingly accurate and comprehensive.

So today we learned that combining Obsidian, Hermes Agent, and LLM Wiki creates a local, AI-powered knowledge system that solves the isolation and forgetfulness problems plaguing most note-taking setups, and that the entire process runs automatically once you set up the pipeline, leaving you free to focus on the ideas that matter.
