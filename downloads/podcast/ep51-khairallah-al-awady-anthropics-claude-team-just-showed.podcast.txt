In this episode you'll learn two things: how Anthropic's new Memory system works and why a feature called Dreaming could transform how AI agents improve themselves over time.

Memory represents Anthropic's third major primitive for building more capable AI agents. The first was MCP, which gave agents access to external tools. The second was Skills, which extended what agents could do out of the box. Now Memory takes centre stage, allowing agents to learn continuously and manage context across extended periods of operation.

What makes this approach particularly elegant is how Anthropic has modelled memory itself. Rather than inventing something entirely new, they've structured it as a file system that agents can interact with using familiar commands like bash and grep. This means developers can leverage tools they already know rather than learning a completely foreign system. According to Anthropic, their Cloud Opus 4.7 model leads the field in this file system based approach to memory.

The design becomes especially powerful when you consider multi-agent environments. Organisations deploying hundreds or even thousands of agents simultaneously need robust safeguards. Memory handles this through permission scopes that distinguish between read-only access, useful for organisation-wide knowledge, and read-write access for task-specific information. Optimistic concurrency using content hashes prevents agents from accidentally overwriting each other's work, which would be catastrophic in large-scale deployments.

Beyond the core functionality, enterprise customers gain version history providing a complete audit trail of every memory change, attribution metadata tracking which agent, session and time made each modification, and a portable API enabling external systems to manage, scan or clean up memory as needed.

The most intriguing element, currently in research preview, is called Dreaming. This operates as a batch asynchronous process running separately from active agent sessions. While agents handle their normal tasks, Dreaming analyses recent transcripts to spot patterns, identify common mistakes and recognise successful strategies. It then produces organised, updated memory content that humans can review before applying. The key advantages are that it runs out-of-band with no latency impact on agent tasks, discovers shared patterns individual agents would miss, and crucially separates memory quality from task completion objectives.

The results speak for themselves. Early testing by Harvey showed a sixfold increase in task completion rates on legal benchmarks. When you combine persistent memory with Dreaming's pattern recognition, you end up with a system where agents genuinely improve over time and share learnings across multi-agent environments. This makes long-running enterprise deployments not just possible but practical for the first time.
