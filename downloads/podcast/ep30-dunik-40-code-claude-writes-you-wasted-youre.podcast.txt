Have you ever wished you had a colleague who could sit right beside you at your terminal and handle the tedious parts of coding while you focus on the creative problem-solving? That essentially describes Cloud Code from Anthropic, an AI coding agent that functions as what its developers call that coworker who does everything on the command line. Unlike traditional code search tools that rely on indexing and retrieval systems, Cloud Code uses something called agentic search, employing commands like glob, grep, and find to explore and truly understand codebases. It's built as a pure agent with clear instructions, powerful tools, and a loop that keeps running until the task is complete, and you can access it through Anthropic APIs, AWS, or GCP.

The versatility of Cloud Code really shines through its range of use cases. For onboarding onto a new project, it helps you quickly grasp codebases, understand patterns, and learn team conventions without weeks of trawling through documentation. When you're planning features, it acts as a thought partner, offering two or three different approaches before you commit to implementation. For the actual code writing, it's excellent at generating unit tests, crafting commit messages, and drafting pull request descriptions. Large refactoring projects like migrating between Java versions or converting PHP to React become far more manageable with Cloud Code handling the repetitive transformations. It also helps with mastering command-line tools, whether that's Git rebasing, Docker operations, or BigQuery queries. For developers interested in automation, the SDK opens up possibilities for CI/CD pipelines and programmatic integration.

Several best practices emerged from the talk that can significantly improve your Cloud Code experience. The CLAUDE.MD file system is fundamental - you can store project-specific instructions, run commands, style guides, and context that the entire team can access. For permissions, using Shift+Tab enables auto-accept, and configuring trusted commands in settings streamlines your workflow considerably. During longer sessions, commands like /clear to reset or /compact to summarize and continue keep things running smoothly. The advice to plan first is particularly valuable - ask Cloud to investigate and propose a plan before diving into changes. If you enjoy vibe coding, remember to run tests frequently, check TypeScript and linting, and commit regularly. When Cloud goes off track, pressing Escape interrupts the process, and double-pressing rewinds the conversation. For complex tasks, running multiple agents in parallel proves effective, and you can expand capabilities by installing CLI tools or adding MCP servers for custom workflows.

Recent updates have brought useful new features. The /model command lets you check and switch between models like Sonnet and Opus. Extended thinking in Claude 4 now works between tool calls, making complex operations more coherent. IDE integrations with VS Code and JetBrains have improved notably. Worth watching is the public Cloud Code GitHub changelog for ongoing updates.

A couple of practical points from the Q&A: only the CLAUDE.MD file in your current working directory loads by default, and Claude 4 shows significant improvement in following CLAUDE.MD instructions compared to earlier versions. For multi-agent setups, using shared files like a tickets.md document works better than trying to share context directly between agents.

Whether you're new to AI coding tools or looking to refine your approach, these practices and features offer a solid foundation for getting the most out of Cloud Code in your development workflow.
