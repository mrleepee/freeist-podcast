¿Ya escuchaste? La versión 0.129.0 de Codex llegó ayer, y trae cinco funciones nuevas muy útiles. Si no la conocías, no te preocupes. Hoy te cuento todo lo que necesitas saber para empezar a usarla hoy mismo.

La primera función es una herramienta para revisar las teclas. Se llama "keymap debug" y funciona con el comando /keymap o /keymap debug. Imagina que estás cambiando las teclas en tu programa favorito y no sabes si el programa entiende bien lo que presionas. Con esta herramienta puedes ver exactamente qué teclas presionas y cómo el programa las interpreta. Es muy útil cuando tienes problemas con las teclas y quieres resolverlos rápido.

La segunda mejora está en la línea de estado. Ahora muestra el número de tu pull request y los cambios en tu rama. Lo más interesante es que puedes hacer clic en estos datos. Solo necesitas presionar la tecla Command en tu Mac y luego hacer clic. Automáticamente se abre tu pull request o tu rama en el navegador. Es muy práctico cuando trabajas mucho entre la terminal y GitHub.

La tercera función es para los fans de Vim. Los desarrolladores agregaron una función que permite usar comandos de Vim dentro de Codex. Puedes activar o desactivar este modo con el comando /vim. Así puedes navegar y editar tu código usando los comandos clásicos de Vim. No es Vim completo, pero tiene las funciones principales que necesitas para trabajar más rápido.

Ahora viene algo muy divertido. El equipo de desarrollo añadió un detalle especial en la actualización. Escondido en la herramienta de debug, encontraron un pequeño cangrejo que aparece como sorpresa. Es un secreto simpático que los desarrolladores incluyeron para hacer más divertida la experiencia de programación.

La última mejora es el nuevo sistema de fragmentos de código. Ahora puedes buscar y usar piezas de código que usas mucho. Con el comando /snippet puedes ver todos tus fragmentos guardados. También puedes crear tu propia colección personal con el comando /snippet add. El sistema muestra solo los fragmentos que funcionan con el tipo de archivo que estás usando. Es muy útil cuando trabajas con código repetitivo y quieres ahorrar tiempo.

En resumen, esta actualización es genial. Trae herramientas para trabajar mejor, funciones especiales como el cangrejo, y formas más fáciles de usar código que ya escribiste antes. Si aún no la instalaste, este es el momento perfecto para hacerlo. Prueba el debug de teclas, el modo Vim, busca el cangrejo, y crea tus propios fragmentos. ¡Feliz programación!
